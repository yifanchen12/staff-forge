# 封印工坊 · 操作说明

## 开始

完整解压游戏包，双击 StaffForge.exe，点击“开启新契约”。已有存档时可继续契约。开启另一份契约需要在游戏内确认，会替换物品与每日进度，但保留已发现的线索、剧情章节和结局。

## 按键

| 按键 | 操作 |
|---|---|
| W / A / S / D | 前进、左移、后退、右移 |
| 鼠标 | 行走时观察；工位中使用界面 |
| E | 靠近并看向工位或线索实物后交互 |
| J | 打开/关闭调查手记，阅读线索、剧情及当前目标 |
| T | 打开进化树；再次按下返回灌注台 |
| Tab | 打开或关闭作品库存 |
| Esc | 返回工坊，或暂停/恢复 |
| 空格 | 灌注台灌注；试法长廊对中央靶施法 |
| 鼠标左键 | 点击按钮；试法时点击靶标施法 |
| R | 在试法长廊重置训练靶 |

## 一天的流程

1. **材料架**：工坊左后侧，每天领取3份灵木与晶核。每份能制作任意一种法杖，剩余材料跨天保留。
2. **组装台**：左前侧。选择材料、杖头、晶核与符文，调整长度、粗细、木色。中央是实时预览，拖动可以旋转。点击“组装法杖”消耗1份材料。
3. **灌注台**：右前侧。每次灌注抽取一次结果。当前概率、强化、灵值、充能均显示在面板中。破碎会失去作品；蓝图仍在组装台，可以用新材料再做。
4. **试法长廊**：正前方。可免费重复试法。火焰爆炸并持续灼烧；冰霜使靶标移动速度降低82%；雷电最多向邻近靶连锁2次。选择散射或范围杖头会改变覆盖范围。
5. **遗物柜**：右后侧。用当前装备的整根法杖兑换一件遗物，没有找零。最多持有3件，同一件只能获得一次。
6. **封印祭台**：工坊后方。交付当前作品，把它的灵值计入今天供能。供能足够后敲钟结束今日。未交付的作品与遗物保留。

## 共鸣与风险

### 概率升级与基础外观

成功升1级，大成功升2级；停滞保持等级，降级减少1级，破碎失去整根作品。界面显示当前五种概率和结果的等级前后变化；结果先保存再播放灯效，退出不会重新抽取。

| 强化等级 | 外形 |
|---|---|
| +0～+2 | 素木原型，逐级增加刻印 |
| +3～+5 | 符文觉醒，分叉护冠与晶核座 |
| +6～+8 | 晶簇冠冕，多棱晶簇与枝状支架 |
| +9～+11 | 悬浮星环，旋转轨道与浮晶 |
| +12 | 封印神器，三重星环、冠尖与放射饰件 |

各阶段内部也会随等级改变细节。火、冰、雷具有不同晶核与灯光颜色；降级会撤去对应结构。+12达到上限后无法继续灌注，可以试法、保留或交付。新外观适用于灌注台、手持模型和读档后的作品。

通常灌注6次充满共鸣，第7次开启3秒保护窗口，期间不会破碎，停滞和降级仍然可能发生。共鸣指环降低门槛；回声棱镜延长窗口。

铁心木、粗杖身和稳固符文降低灌注风险，但会减慢施法。更长的杖身增加威力，施法也更慢。先看清当前概率，再决定是否继续。

交付/交换立即消耗当前作品。库存右侧可切换另一根法杖。若作品价值已经足以填补今日缺口，可以收手。

## 契约胜负

每日供能要求依次为200、400、700、1100、1700。供能不足增加一道裂隙，第三次不足失败。只要未出现第三道裂隙并完成第五夜结算，就完成契约。

## 设置与存档

Esc 菜单提供音量、灵敏度、全屏和镜头震动。暂停时共鸣计时、训练靶与灼烧冻结。

经济操作立即自动保存，并每两秒保存当前计时；关闭窗口也会保存。通常位置为 %APPDATA%\Godot\app_userdata\铸杖模拟器 · 封印工坊\，包含 run.json、run.backup.json、settings.json。

主存档异常时尝试恢复有效备份，损坏文件以 run.corrupt.*.json 保留；两个存档都不可用时提示并开启新契约。不要在游戏运行时编辑存档。

本地包无需引擎、账号或网络。法杖外观与训练靶效果均在本地运行。

## 轮回调查（0.3）

先在材料架旁的小抄写台调查账册。六处线索以实物藏在工坊里：账册、刻痕、镜片、星盘、墙龛回信与瓶中便条。靠近并看向它们按 E。尚未满足剧情条件的痕迹暂时无法读取，已经发现的内容可反复阅读。

按 J 查看手记。它记录已发现线索、章节、触发时的轮回编号，并给出下一步位置与法杖属性要求。交付前，祭台会提示“此作品将触发…”或“仅计入供能”；没有满足剧情条件的作品仍正常供能并消耗。

第二章需要在第一章之后的新轮回触发，第三章还需要再进入后续轮回。完成或失败后重开，或暂停→保存并返回主菜单→开启新契约，都会进入下一轮。每轮仍是原来的五夜契约；新的材料、物品、遗物进度从头开始，记忆保留。最终选择只会确定一次，之后返回工坊继续制作时仍保留结局。剧情阅读与手记会暂停共鸣计时。

工坊会留下章节痕迹；门上记忆刻印逐渐显现，回声台呈现最近提交的元素与等级，结局改变门前灯色。这些变化随存档与轮回恢复。

## 三层进化树（0.3）

概率灌注仍然决定等级。达到门槛后按 T，自行选择该层分支；不选分支也能继续灌注。一次大成功跨过门槛后仍可补选。

| 门槛 | 选择 | 属性效果 | 外观 |
|---|---|---|---|
| +3 | 荆棘枪冠 / 祷告香炉 / 星轨罗盘 | 威力×1.30且间隔×1.12 / 范围×1.35且稳定×1.12 / 间隔×0.80且威力×0.92 | 分叉长枪 / 六叶香炉与垂链 / 双轴星盘 |
| +6 | 棘骨缠身 / 圣匣晶脊 | 威力×1.18且稳定×0.90 / 稳定×1.25且范围×1.12 | 螺旋棘骨 / 三段晶匣 |
| +9 | 六曜伴星 / 折光双翼 | 范围×1.30 / 间隔×0.85且威力×1.12 | 六颗公转浮晶 / 机械光翼 |
| +12 | 沿现有道路自动加冕 | 不额外增加分支倍率 | 对应结构上的神器冠尖 |

每层只选一次，三层共12种组合，叠加到原元素、杖头、材质与尺寸属性上。先选前一层才能选择后一层。选完返回灌注台即可看到实物，手持与试法共用相同配置。

降到门槛以下时，对应几何和属性暂时休眠，选择记录保留；重新升上来会恢复。破碎或交付后作品及其分支一起失去，新法杖可以走不同道路。旧版法杖载入后分支未选，可按已有等级直接补选。

# 铸杖模拟器：已批准实施方案

用户于 2026-10-09 明确要求实施。交付完整 Godot 工程、独立 Windows x64 游戏包、操作说明、测试记录。5天流程，预计20–30分钟，第一人称幽暗工坊；不包含 Steam 上传、SDK、联网多人、自由雕刻或收费 Lux3D 生成。

## 玩法
领取材料 → 组装 → 灌注 → 试法 → 交付或换遗物 → 次日。
WASD移动、鼠标观察、E交互；工位固定视角，Esc退出。库存存放物品，手持模型提供反馈。
3种杖身、3种杖头、火/冰/雷晶核、迅捷/稳定符文；实时调整长度、粗细、颜色。材料改变稳定度和施法速度；头部决定集中、散射、范围；长度提升威力但减慢施法，粗细提升稳定但减慢施法。
试法使用多个训练靶；火产生爆炸和灼烧、冰减速、雷连锁；显示伤害、范围、施法间隔，不消耗材料。
灌注结果：成功+1、大成功+2、停滞、降级-1、破碎。显示概率、价值、充能，破碎保存蓝图。
6格后下一次灌注触发3秒共鸣，免于破碎。6种遗物，最多装备3件，消耗满足价格的法杖交换。
5天完成封印供能契约，累计3次不足则失败，剩余法杖和遗物跨天继承，重开清空本局。

## 独立初始数值
每天3份材料；法杖基础价值80，强化倍率1.5，上限12级；贡额200/400/700/1100/1700。
基础破碎率等级×3.5%，应用稳定度和遗物修正；其余概率按成功65%、大成功10%、停滞15%、降级10%分配。
集中在数值资源里，以固定种子验证后再调参，记录变化。

## 具体实现文件边界
project.godot/main.tscn：工程入口和导出配置。
scripts/rules.gd + data/balance.json：唯一规则和可调数值。
scripts/staff_visual.gd + scripts/spells.gd：模块化模型和施法/训练靶。
scripts/workshop.gd + scripts/ui.gd：场景、玩家和完整工位UI。
scripts/save_store.gd：存档边界与设置。
tests：无外部框架的规则和集成检验。
assets/：实际使用素材；docs/：来源、操作和验证记录。
执行顺序：独立模块检验→组装验证→主场景接入→独立包验证。

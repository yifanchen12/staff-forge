# 哥特式炼金工坊与法杖进化

用户授权：概率灌注升级，升级后改变法杖样式，允许魔改与灯效，重做场景；已选择哥特式炼金工坊。

复用：rules.gd 的概率、随机状态和经济规则已经实现，保留唯一规则来源；StaffVisual.rebuild(design, level) 已被手持、灌注台和展品共用；workshop.gd 提供碰撞、工位与固定镜头。Godot原生几何、材质、灯光与Tween足够，不新增依赖或收费模型。

改动边界：
- staff_visual.gd：按强化等级派生五阶段外形，每级增加可观察细节；元素颜色、悬浮晶簇与旋转星环；降级时同步回退，无新存档字段。
- workshop.gd：重建黑曜石/黄铜哥特式建筑与工位，保留交互坐标和通行碰撞；灌注仪式反馈与等级前后显示。
- gothic_scene.gd：仅负责工坊建筑、材质装饰与环境灯光，移出控制器中的旧仓库几何；不参与库存和规则。
- stone.gdshader、wood.gdshader：细尺度石材与木纹，避免旧场景巨型砖块与平涂木块。
- ui.gd：强化阶段名称、升级预告与结果反馈；原有操作接口保持。
- tests/ 与现有集成验收：概率升/降级、外观等级映射、尺寸连接、三系颜色与存档恢复检查。
- docs/、Windows发行包和源码包：更新实际画面、操作及验收证据。

不改动贡额、遗物价格、胜负、存档结构、多人或平台接入。低等级简单、高等级繁复，灯效不能遮住晶核与概率文字；保护窗口继续按已保存规则计算。

顺序与验收：
1. 外观模块：0/3/6/9/12级结构、元素和连接位置可验证。
2. 场景与仪式整合：保留W/E、组装、概率灌注、交付、换遗物、暂停与读档，成功反馈匹配实际结果。
3. 独立包：原规则检查、升级外观检查和实际GPU截图；核对画面与日志，导出并打包。

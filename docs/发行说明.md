# 铸杖模拟器 · 封印工坊

完整解压后，双击同一文件夹中的 StaffForge.exe 开始游戏。保留 StaffForge.pck；无需安装Godot，无需账号或联网。

版本0.3：轮回悬疑主线、6处环境线索、指定属性交付触发的4章记忆与2种最终选择；+3/+6/+9三层进化树，12种分支搭配及对应外观与施法属性。新契约会清空物品，但保留轮回记忆。已有0.2存档自动兼容。

WASD移动，鼠标观察，靠近并看向工位按E。先到左后侧材料架领取材料，再去组装台。Esc返回/暂停，Tab库存，空格灌注/试法。J调查手记，T进化树。剧情从材料架旁的小账册开始。
